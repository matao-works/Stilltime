Stilltime — 定时防睡眠

支持 macOS 13 及以上，Apple 芯片与 Intel Mac。

安装：
1. 将 Stilltime.app 拖到 Applications（应用程序）。
2. 从“应用程序”打开 Stilltime。
3. 选择持续时间，点击“开始防睡眠”。

屏幕开关：
“保持屏幕点亮”：防睡眠期间保持屏幕亮着。
“允许屏幕自动熄灭”：屏幕按系统设置熄灭，电脑继续运行。

结束：
计时到期会恢复系统自动睡眠设置，不会立即强制睡眠。
也可以随时点击“关闭防睡眠”。菜单栏内可打开窗口或退出。

首次打开：
本版本为本地签名版本，尚未经过 Apple Developer ID 签名及公证。
如果 macOS 拦截，仅在确认下载来自本项目且信任此软件后，
按 Apple 官方说明在“系统设置 → 隐私与安全性”中选择“仍要打开”。
公司受管理电脑可能不允许执行此步骤，请联系 IT。
https://support.apple.com/102445

更新：
先从菜单栏退出旧版本，再用新版本替换“应用程序”中的 Stilltime.app。
使用记录保存在本机，替换 app 不会删除记录。

卸载：
先退出 Stilltime，再把“应用程序”中的 Stilltime.app 移到废纸篓。
无需安装 Swift、Xcode、Homebrew，也无需联网使用。

注意：
防睡眠针对自动闲置睡眠；手动睡眠、合盖、关机和公司管理策略仍可能中断任务。
